Supermarket Sales Dashboard | Power BI

About the Project

This project is an interactive Supermarket Sales Dashboard created using Microsoft Power BI. It presents supermarket data through key performance indicators and visualizations to help explore customer and sales-related information.

Tools Used

- Microsoft Power BI Desktop
- Data Analysis
- Data Visualization

Dashboard Highlights

- KPI Cards: Total Customers, Average Rating, Average Revenue, and Total Quantity.
- Customer Analysis: Explore customer-related information, including ratings and branch-level comparisons.
- Product Line Analysis: Compare revenue across different product lines.
- City Analysis: Explore customer-related data across cities.
- Gauge Visualization: Display the payment-method count.
- Tables: View branch, product line, and customer-type information.
- Interactive Filters: Filter the dashboard by city, payment method, customer type, gender, month, and date.

Project Objective

The objective of this project is to present supermarket data in an interactive and easy-to-understand format. The dashboard allows users to explore different aspects of customer and sales-related information using visual reports and filters.

Project File

- "super_market.pbix" — The Power BI dashboard file.

How to Open the Dashboard

1. Download the "super_market.pbix" file from this repository.
2. Open Microsoft Power BI Desktop.
3. Open the downloaded PBIX file.
4. Explore the report using the available visuals and filters.
